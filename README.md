# Noble Darwin - Developer Showcase Platform

A modern developer showcase and digital agency web application built with Next.js (App Router), TypeScript, and Tailwind CSS. Features dark-themed Bento Grid layouts, interactive components, and responsive design.

---

## Key Features

- **Bento Grid Architecture:** Clean, modular grid layout displaying core capabilities, featured projects, and client testimonials.
- **Fluid Micro-Interactions:** Subtle transitions powered by Framer Motion and modern Tailwind utilities.
- **Modular Component Design:** Decoupled UI components (Navbar, HeroSection, BentoGridSection, ProjectsShowcase, WorkflowProcess, ContactSection).
- **Responsive Layout:** Optimized viewports from mobile to ultra-wide displays.

---

## Technical Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Animation & Icons:** Framer Motion, Lucide React

---

## Getting Started

```bash
git clone https://github.com/hmkborhanuddin2004-tech/noble-darwin-app.git
cd noble-darwin-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
